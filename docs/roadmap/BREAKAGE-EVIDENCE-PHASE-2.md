# Breakage Evidence — Phase 2

**Status:** PENDING

Phase 2 covers advanced evidence architecture beyond the v1 document-level photo model. No implementation is scheduled in this document; it records future scope only.

## Topics

- **Item-level photos** — attach evidence images to individual breakage line items
- **Line attachments** — non-image or supplemental files per line
- **Incident photos** — dedicated incident-scene capture separate from item proof
- **Hybrid evidence model** — combine document-level, line-level, and incident evidence with clear precedence rules
- **Item-grouped PDF evidence** — evidence gallery sections grouped by item rather than flat FIGURE numbering only
- **Photo register** — indexed register of all evidence assets with metadata for audit retrieval
- **Audit traceability improvements** — stronger linkage between photos, approvals, accountability, and financial impact in exports

## Out of scope for Phase 2 planning doc

- Schema migrations
- API contract changes
- UI implementation
- PDF gallery redesign (v1 architecture remains closed until Phase 2 is approved)
