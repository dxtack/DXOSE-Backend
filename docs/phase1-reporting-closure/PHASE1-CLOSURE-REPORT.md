## 3. Known Limitations

1. **Grouped variance reports** (`variance-by-location`, etc.) reuse the line-level table; columns may not match grouped shape.
2. **Manual UAT** for Screen = Excel = PDF must be run on staging with real tenant data (automated script covers totals math only).
3. **Valuation PDF** may use a different code path than analytics PDF — verify separately if valuation export is added.
4. **Summary report** print CSS may differ slightly from PDF export if summary PDF is not yet unified on `generateReportPDF`.
5. **Screenshots** are not committed to the repo — capture during staging UAT (see checklist below).
